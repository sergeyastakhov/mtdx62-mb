# `mtdx62-mb` Python library

`mtdx62-mb` is an asynchronous Python library for reading from and writing to MTDX62-MB human presence sensor devices using the Modbus protocol.

The MTD062-MB and MTD262-MB are human presence sensors manufactured by the Chinese company Zhejiang Oujue Electronic Technology Co., Ltd.

Support for the Home Assistant integration is maintained separately in [mtdx62-mb-hass](https://github.com/sergeyastakhov/mtdx62-mb-hass).
